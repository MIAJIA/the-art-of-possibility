数据从哪来，哪些是我的概括

民主问责用 V-Dem 数据集（第 16 版，1789–2025 年）的选举民主指数，范围 0 到 1。0.5 是参考线。

国家能力是这里自己合成的指数，书里没有这个数。取 V-Dem 的四项指标：国家实际控制的领土比例、行政是否严格公正、财政主要靠什么收入、官员任用看关系还是看能力。四项分别对应书中讲的国家能力来源：常备军、财税、行政体系、文官制。各项按 1900–2025 年全部国家标准化后取平均，再线性换算到 0 到 1。参考线 0.55 是 1900–2025 年的世界平均。它与世界银行“政府效能”指标（1996–2024 年）的相关系数是 0.85。

这个指数的两个局限。它只衡量行政是否规范，动员和执行的力度不在其中。它和民主程度本身相关（相关系数约 0.74），左上角偏空有一部分是指标造成的。

法治用 V-Dem 的法治指数。经济发展用 V-Dem 收录的人均 GDP 估计值，换算成同年美国水平的百分比；数据到 2019 年为止，之后沿用 2019 年的值。世界平均是各国简单平均，每国一票，不按人口加权。

书的内容。章节和小节标题来自公开的目录。每个国家的缘起、转折、结果，各章的看点，以及四个象限的名字，是我根据公开史实和上面的数据写的概括，不是书中原文。俄罗斯是音频课里的案例，成书时那一讲换成了法国。
